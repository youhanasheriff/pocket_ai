# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report vulnerabilities privately using GitHub's security advisories:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability** (or open
   <https://github.com/youhanasheriff/pocket_ai/security/advisories/new>).
3. Describe the issue, the affected files or versions, and steps to reproduce it.

Reports are handled privately through the advisory, so details are not
disclosed publicly until an issue has been addressed.

## Scope

Pocket AI Guardian runs fully on-device. Reports about the code in this
repository (for example, unsafe handling of model files or input images) are in
scope. Vulnerabilities in third-party dependencies should be reported to the
respective upstream projects.
